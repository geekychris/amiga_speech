# Samples

Rendered from `tests/data/sentences.txt` (`make samples`); 16-bit mono WAV.

| File | What |
|---|---|
| `NN_natural.wav` | Natural voice (diphone LPC), default settings |
| `NN_classic.wav` | Classic voice (formant), default settings |
| `NN_classic_nrl.wav` | Classic voice, rule-only (NRL 1976) translation |
| `NN_amiga68k.wav` | Original AmigaOS 68k narrator.device 37.7 with translator.library 37.1, captured in FS-UAE (8-bit at 22,233 Hz) |
| `NN_amiga68k_phonemes.txt` | the phoneme string translator.library 37.1 produced |

1. Hello, I am your Amiga.
2. The quick brown fox jumps over the lazy dog.
3. Do you enjoy using your Amiga?
4. In 1985, the Amiga 1000 cost $1,295 and had 256 kilobytes of memory.
5. When the narrator device was written, it had to fit into a few kilobytes of memory and run on a seven megahertz processor, so every sound was described by a handful of numbers.
6. The colonel from Worcestershire read about cardiomyopathy, phthalates and the archipelago.
7. Please call me at 3:30 on the 21st, not the 22nd.
8. Workbench, Kickstart and AmigaOS 4.1 still run on the X5000 today.
